# Why this file exists: timm==1.0.28 declares `huggingface_hub` and
# `safetensors` with no version bounds, and torchvision pulls `pillow`
# unbounded. Installing timm alone therefore resolves whatever is newest on
# the build date, so two builds of the same Dockerfile can ship different
# decode and serialization runtimes without any requalification. trainer.py
# imports PIL and safetensors directly, so that drift is semantic, not
# cosmetic -- Pillow in particular owns the EXIF orientation behaviour the
# training decode path was aligned to.
#
# Deliberately absent:
#   torch, torchaudio, torchvision  -- supplied by the digest-pinned base
#     image; their +cu128 local versions are not resolvable from PyPI, so
#     constraining them here would break the build rather than pin it.
#   numpy and other conda-supplied packages -- recorded in the freeze only as
#     file:// build artifacts, which carry no expressible version. They are
#     pinned by the base image digest.
#
